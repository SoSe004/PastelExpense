📲 Install as Standalone iPhone App

  1. Host this single index.html file on Netlify Drop or GitHub Pages and open the link in iPhone Safari.
  2. Tap Safari's Share icon (square with upward arrow) and choose Add to Home Screen.
  3. Keep Open as Web App turned ON and tap Add—PastelLedger will launch full-screen with its pastel icon and work 100% offline.
